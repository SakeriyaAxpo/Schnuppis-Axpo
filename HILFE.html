A2: Fertige Texte für deine Website

Titel: Energie entdecken

Einleitung: Entdecke drei Energiequellen. Teste danach dein Wissen in fünf Fragen und prüfe deine Punktzahl.

Sonne: Eine Photovoltaikanlage wandelt Sonnenlicht in elektrische Energie um.

Wasser: Wasser treibt in einem Wasserkraftwerk eine Turbine an. Ein Generator erzeugt elektrische Energie.

Wind: Wind bewegt die Rotorblätter einer Windanlage. Die Drehbewegung wird zur Stromerzeugung genutzt.

Frage 3: Welche Energie nutzt ein Wasserkraftwerk? Antworten: Energie des Wassers (richtig), Energie aus Erdgas, direktes Sonnenlicht.

Frage 4: Was treibt die Rotorblätter einer Windanlage an? Antworten: eine Batterie, Wind (richtig), ein Solarmodul.

Frage 5: Welche Einheit steht für elektrische Leistung? Antworten: Kilowattstunde, Meter, Watt (richtig).

A4: Die Auswertung verstehen
if (document.getElementById("frage1").value === "richtig") {
  punkte = punkte + 1;
}

getElementById sucht die ID. .value liest die Auswahl. === vergleicht. if führt den Inhalt in { } nur bei erfüllter Bedingung aus. Kopiere den Block viermal und ändere die IDs. Alle Prüfungen stehen innerhalb von auswerten() und vor der Ergebnisanzeige.

let punkte = 0; muss bei jedem Klick neu ausgeführt werden, damit alte Punkte nicht mitgezählt werden.

A5: Drei Ergebnisbereiche
if (punkte === 5) {
  ergebnis.textContent += " - Alles richtig!";
} else if (punkte >= 3) {
  ergebnis.textContent += " - Gut gemacht, versuche es nochmals.";
} else {
  ergebnis.textContent += " - Lies die Karten und versuche es erneut.";
}

+= hängt Text an. Die erste passende Bedingung gewinnt. Du darfst die Rückmeldungen direkt übernehmen oder kurz anpassen.

A5: Neustart

Kopiere die vorhandene Zeile in neuStarten() für die anderen vier IDs. Ein leerer Wert setzt die Auswahl auf den Platzhalter. Ergänze innerhalb der Funktion:

document.getElementById("ergebnis").textContent = "Noch nicht ausgewertet.";
A6: Fehlersuche

Teste ohne Häkchen, nur A, nur B, nur C und alle drei. Vergleiche die Anzeige mit dem erwarteten Ergebnis. Du brauchst nichts zu notieren. Suche danach die verantwortliche Zeile. .checked ist wahr, wenn ein Kästchen angekreuzt ist. Die drei Fehler betreffen das Zählen, die angezeigte Höchstpunktzahl und die Bedingung für den Lobtext.

Nichts passiert oder ein Button reagiert nicht
  1. Speichere alle Dateien und lade den Browser neu.
  2. Prüfe, ob Editor und Browser denselben Ordner verwenden.
  3. Vergleiche Dateinamen, IDs, Anführungszeichen und Klammern.
  4. Prüfe, ob alle fünf Felder existieren. Ein fehlendes Feld kann die Auswertung unterbrechen.
  5. Mache die letzte Änderung rückgängig und probiere einen kleineren Schritt.
Zusatz: Fehlende Antworten

Lies die fünf Werte am Anfang von auswerten() ein. Ein leeres Feld hat den Wert "". Verbinde die fünf Vergleiche mit || (oder). Zeige bei mindestens einem leeren Feld einen Hinweis und beende mit return;. Passe Test 1 an: Statt 0 Punkten wird ein Hinweis erwartet.

Zusatz: Schleife
for (let i = 1; i <= 5; i++) {
  if (document.getElementById("frage" + i).value === "richtig") {
    punkte = punkte + 1;
  }
}

i beginnt bei 1; i++ erhöht um 1. Die Schleife läuft bis 5. Ersetze die alten fünf Prüfungen, sonst werden Punkte doppelt gezählt. Führe die Tests erneut aus.

B2: Fertiger Baustein für leere Antworten

Füge dies am Anfang von auswerten() ein, vor dem Zählen. Bei sechs Fragen ergänzt du einen Vergleich für frage6.

if (document.getElementById("frage1").value === "" ||
    document.getElementById("frage2").value === "" ||
    document.getElementById("frage3").value === "" ||
    document.getElementById("frage4").value === "" ||
    document.getElementById("frage5").value === "") {
  document.getElementById("ergebnis").textContent = "Bitte beantworte alle Fragen.";
  return;
}

|| bedeutet «oder». return beendet diesen Versuch, bevor Punkte gezählt werden.

B5: Bausteine für deinen Nachtmodus

Füge in index.html innerhalb von header diesen Button ein:

<button id="modus" type="button" aria-pressed="false">Nachtmodus</button>

Füge am Ende von style.css die Regeln hinzu. Passe die Farben nach Wunsch an, behalte guten Kontrast.

body.nacht { background: #17172c; color: #eeeeff; }
.nacht h2, .nacht h3, .nacht .topbar span { color: #bfbfff; }
.nacht .karte, .nacht section[aria-labelledby="quiz-titel"] {
  background: #252540; border-color: #494966;
}
.nacht select { background: #17172c; color: #eeeeff; }
.nacht #ergebnis { background: #34345b; color: #eeeeff; }
.nacht footer { color: #bcbcd1; }

Füge am Ende von script.js hinzu:

document.getElementById("modus").addEventListener("click", function () {
  const nacht = document.body.classList.toggle("nacht");
  this.textContent = nacht ? "Tagmodus" : "Nachtmodus";
  this.setAttribute("aria-pressed", String(nacht));
});

classList.toggle schaltet die CSS-Klasse ein oder aus. Probiere beide Zustände aus.
